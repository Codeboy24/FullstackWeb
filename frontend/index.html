📅 Fixture Record Specification

In accordance with Question 9, a Fixture record represents an upcoming team match event. In this single-table design, player_name, position, and jersey_number are stored as NULL.

When you click Save Record, the backend will issue an INSERT INTO sports (player_name, position, jersey_number) VALUES (NULL, NULL, NULL) query to MySQL.

💡 Architecture & Local Network Access

1. Pure MySQL Execution

Every read, create, update, and delete executes raw SQL statements via mysql2/promise pool on port 3306. There are zero mocks or in-memory arrays.

2. Local Network (LAN) Connectivity

The Express server binds to 0.0.0.0, allowing any phone, laptop, or tablet on your Wi-Fi network to connect to http://<YOUR_PC_IP>:3000.

3. Polymorphic NULL Columns

Rows 6–10 have NULL for player fields. The frontend uses defensive rendering to display clean badges rather than literal null text.
